# CC Elevate — Instagram Audit

Mini-audit Instagram personalizzato, generato dall'AI (Anthropic/Claude) a partire dalle risposte dell'utente.
Frontend React (CRA + CRACO, Tailwind), backend FastAPI + Motor + Resend, database MongoDB Atlas.

- Stile: nero/oro (Playfair Display + Manrope).
- Rotte: `/` landing · `/audit` wizard · `/deep-audit` consulenza (Calendly) · `/admin` dashboard lead · `/privacy` informativa.
- Privacy: informativa interna nLPD + GDPR; due consensi separati (privacy obbligatoria, newsletter facoltativa).

Deploy: vedi `DEPLOY.md`.
